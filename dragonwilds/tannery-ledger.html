05 Field Manual

How to use the Production Ledger.

Dragonwilds 1.0

Start with the job you are trying to solve.

Use Profit Workshop to test a money-making run, Production Planner to size the processing floor, Merchant Catalog to assemble a purchase, and Server Bank to record shared funds. Every field begins blank so the ledger only calculates from values you enter.

Profit Workshop Production Planner Merchant Catalog Server Bank Reference
01

Profit Workshop Test the return

Calculate from materials, a Chit budget, or a profit goal.

  1. Choose Dragonwolf Hide or Ash Log Cycle.
  2. Select Material Quantity when you know how many hides or logs you will buy. Select Chit Investment when you know how much currency you want to spend. Select Profit Goal when you know how much net Chit you need to earn.
  3. Enter the amount. The result board calculates whole purchasable units, actual spend, gross return, profit, ROI, output, and either unspent Chits or goal surplus.
  4. Review the trip footprint. It compares currency, purchased-material, and finished-output stacks against the active inventory size.
  5. Choose Plan this batch to send the calculated material quantity into Production Planner.
Dragonwolf example

500 hides cost 22,500 Chits. They produce 500 Draconic Leather worth 30,000 Chits, leaving 7,500 Chits profit.

Ash example

A 10,000-Chit budget buys 3,333 logs for 9,999 Chits. Those become 6,666 charcoal worth 19,998 Chits, leaving 9,999 profit and one unspent Chit.

02

Production Planner Size the floor

Estimate processing time and station requirements.

  1. Choose the batch method and enter the number of hides or logs being processed.
  2. Enter an optional target completion time in minutes.
  3. For leather, enter your tannery count. For Ash production, enter both sawmill and kiln counts.
  4. Enable the hotbar toggle only when all eight hotbar slots are available for the run.
  5. Compare the current run estimate with the recommended station plan and inventory meter.

Balanced Ash line: one sawmill produces two planks per log, so each sawmill should be paired with two kilns. Processing estimates use 10 seconds per item at each stage and exclude manual transfer time.

Tannery benchmark: one tannery holds a 99-hide stack. Twenty-four tanneries take one standard inventory in a single unattended load; 32 take a full inventory plus hotbar.

03

Merchant Catalog Build a requisition

Price one item or prepare a multi-merchant order.

  1. Search by item name or filter the list by Iasadair, Domri, Beartach, materials, or blueprints.
  2. Select the arrow beside an item, enter the desired quantity, and review its total cost and required item slots.
  3. Add the item to the requisition. Repeat for every item needed.
  4. Use Peak Carry to determine whether the exact Chit amount and purchased goods fit within one trip. The calculation assumes spent Chit slots become available for incoming stock.
  5. Review Dragonwolf Replenishment to see how many hides, how much working capital, and how much processing time would recover the full purchase cost.
  6. Signed-in members can submit the complete order as a Server Bank purchase request.

Blueprints are one-time unlocks, so the planner limits each blueprint line to one. Merchant prices reflect the current values read directly from the in-game menus.

04

Server Bank Keep a shared trail

Request, approve, and reconcile communal Chits.

Guest

Can use every public calculator and browse the merchant catalog. Bank data remains hidden.

Member

Can view the shared balance, submit deposits or withdrawals, request catalog purchases, and see personal requests.

Administrator

Can see the full request queue, approve or reject requests, and post documented balance adjustments.

  1. Members choose Deposit or Withdrawal, enter the amount and reason, then submit the request.
  2. Catalog purchase requests are generated automatically from the active requisition.
  3. An administrator verifies the in-game movement and approves the request. Approval updates the balance and creates a permanent ledger entry.
  4. Administrators set the number of Iron Chests allocated to the bank. Each chest adds 64 slots, and each slot holds one 9,999-Chit stack.
  5. Administrators enable the Admin Controls toggle when they need chest settings, the full request queue, approvals, or reconciliation controls. It starts off again after every page load.
  6. Administrative adjustments require a reconciliation note so corrections remain auditable.

Important: approvals and positive adjustments cannot exceed the configured physical chest capacity. This bank is still a shared bookkeeping ledger; it cannot automatically move Chits inside Dragonwilds.
